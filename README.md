# Haley Johnson – Personal Website

This is my personal website for ISDS 4125, built with HTML, CSS, and JavaScript and hosted on GitHub Pages. It opens on a home page with my profile, skills, experience, and contact information, and has separate pages for my resume and for a project I'm building: an AI email automation in n8n, complete with a small "Try It Yourself" demo.

The site also greets visitors with a language pop-up (English, Spanish, or Italian) that translates all three pages. My favorite part is the wink: after you pick a language, my photo zooms in and my eye sparkles, because it captures my personality better than any sentence could.

**Live site:** https://haleywaley.github.io/resume-website/

**Built with:** HTML, CSS, JavaScript, VS Code, Git, GitHub Pages, and Claude as my AI coding assistant.

## Reflection

The hardest part at first was blending the assignment's directions with the layout I pictured in my head. The moment it clicked was when Claude sent me finished files to download instead of code to paste, and I didn't understand why that would work. I asked, and learned that my code doesn't live inside VS Code at all. It lives in files in a folder on my computer, and VS Code, the browser, and Git all read from that same folder. That's why unsaved changes don't show up in the browser, and why one folder should match one GitHub repo. Once I understood that, the rest made sense: `styles.css` is the backbone that brings every page to life, and the JavaScript in `script.js` is what makes the animations move.
