AI Email Automation

A self-built workflow in n8n that reads incoming emails and answers them automatically, created during my Analytics/Marketing internship at Ford Gum.

The Problem

Part of my internship involved checking a shared inbox and answering routine inquiries by hand, the kind of repetitive work you'd expect at a front desk. I'm drawn to the technical side of business, so instead of just doing the task, I turned it into an opportunity to build something.

How It Works

  • Trigger: An IMAP trigger watches the inbox and starts the workflow the moment a new email arrives.
  • Parse: The workflow pulls out the sender, subject, and message so the content can be analyzed.
  • Match: Conditional logic compares the inquiry against a reference file I created, an answer key that maps common questions to the right responses.
  • Draft: An AI inference API writes a personalized reply using the matching answer.
  • Send: The reply goes back to the sender automatically, with no manual checking required.

Impact

  • Replaced manual inbox checking with a workflow that runs on its own
  • Routine inquiries get answered as soon as they arrive instead of waiting for someone to check the inbox
  • Consistent, accurate replies, because every answer comes from the same approved answer key
  • Frees up time for higher-value work like analytics and reporting

My Role

This was a self-initiated project. Nobody asked me to automate the inbox. I designed the workflow, built each step in n8n, wrote the answer key the AI draws from, and tested it until the replies were accurate.

Tools & Skills Used

n8n, IMAP email triggers, conditional logic, AI inference APIs, API integration, workflow design
