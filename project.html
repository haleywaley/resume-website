AI Email Automation

An n8n workflow that reads incoming customer emails, looks up order details, and drafts replies with AI, built during my Analytics/Marketing internship at Ford Gum.

The Problem

Part of my marketing internship was checking a shared inbox and answering the same customer questions by hand, the kind of repetitive work you'd expect at a front desk. It wasn't the work that excited me, but the problem behind it did. So instead of just doing the task, I turned it into something I wanted to build: an automated assistant that reads each message, figures out what the customer needs, and answers it.

A Look Into the Project

This is the workflow as I'm building it. Each box is a node: a trigger, a decision, an API call, or an action. I'm mapping the path an email takes through the system, then configuring and testing each branch one at a time before connecting it to the next. The warning icons mark nodes that still need credentials or configuration.

How It Works

  1. Trigger: A Microsoft Outlook trigger starts the workflow whenever a new email arrives.
  2. Sort: Conditional logic checks whether the email is about an order or a general question.
  3. Look up: For order questions, the workflow pulls out the order number and calls the Square API over HTTP to find the order. If there's no order number, it emails the customer to ask for one.
  4. Match: General questions are matched against an answer key I wrote, a document of common questions and approved responses.
  5. Draft: Claude, Anthropic's AI model, writes a personalized reply using the order details or the matching answer.
  6. Check: A confidence check sends replies scoring 95% or higher straight to the customer. Anything lower alerts the team for a manual review.

What It's Built to Do

  • Answer routine questions without anyone having to watch the inbox
  • Look up order status in seconds instead of searching by hand
  • Keep replies consistent, since every answer comes from the same approved answer key
  • Keep a human in the loop: low-confidence replies go to the team instead of the customer

My Role

Nobody asked me to automate the inbox. I designed the workflow, built each node in n8n, wrote the answer key the AI draws from, and set up the order lookup through the Square API. I'm now configuring and testing each branch to make sure the replies are accurate before it goes live.

Tools & Skills Used

n8n, Microsoft Outlook, Square API, HTTP requests, Claude (Anthropic), conditional logic, prompt design, workflow design
